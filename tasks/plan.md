# 周报项目实施计划

目标：交付 Vue + FastAPI + PostgreSQL 周报系统及独立 Docker Compose 运行环境。用户需求与详细规则以本次会话中批准的方案为准。

纵向步骤：

1. 数据表、迁移、会话登录及界面骨架。
2. 用户管理、密码与个人字典。
3. 周历、任务编辑、自动保存与版本冲突。
4. 行复制、跨周复制及全员只读汇总。
5. 响应式、安全、集成测试、浏览器测试、文档。

每一步执行实现、测试、实际运行验证、修正。开发 Compose 名称为 `zhoubao-01a13375`，测试为 `zhoubao-01a13375-test`；不修改其他项目资源。
